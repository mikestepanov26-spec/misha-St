О сайте

Это учебный проект по курсу веб-технологий в ВГУ. Здесь собрана практика по HTML, CSS, Bootstrap и JavaScript с публикацией на GitHub Pages.

  • HTML5 — структура всех страниц сайта
  • CSS3 + Bootstrap 5 — сетка, карточки, модальное окно, collapse и тёмная тема
  • JavaScript — DOM, события, проверка формы и загрузка проектов из JSON через fetch()
